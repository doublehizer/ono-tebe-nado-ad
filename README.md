# Оно тебе надо

Проектная работа 1 спринта курса «Фронтенд-разработка» в Яндекс Практикуме — одностраничный сайт аукциона вещей, в которые никто не верил.

Ссылка на репозиторий: https://github.com/doublehizer/ono-tebe-nado-ad

## Что сделано

- семантическая разметка: `header`, `main`, `section`, `article`, `address`, `footer`;
- раскладка на Flexbox и Grid, классы по БЭМ;
- шрифт Raleway подключён локально через `@font-face` (woff2 и woff);
- один оверлей для обложки и карточек лотов;
- ссылки на телефон и почту с `tel:` и `mailto:`.
